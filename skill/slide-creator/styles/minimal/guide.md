# Minimal style

Black type, white background, square edges, aligned columns and one restrained accent. Use it as a safe corporate default for mixed content, client updates and internal reviews.

Make each content title a complete conclusion. Prefer one chart or a few numbers to a crowded page. Use `cols` and `card` for comparisons, `summary` for an executive overview, and `dense` only when a table needs it. Keep labels short and leave space around the main point.

The dark scheme reverses the canvas while keeping the same grid. The style uses Aptos and Segoe UI fallbacks only. All design values live in `style.json`; edit the deck Markdown for content. The showcase in `examples/showcase` is the reference test.
